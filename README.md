# terepasztal

Isometric train logistics with a gacha roster. Vite + TypeScript + PixiJS v8.

```
npm install
npm run dev      # http://localhost:5173
npm run build
npm run lint
```

See `MILESTONES.md` for progress notes. Procedural placeholder art lives in `src/art`; drop a real
`public/assets/<group>.png` + `<group>.json` (same frame names) to replace a group.
